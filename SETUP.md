# RetailIQ: Retail Business Intelligence & Analytics Platform

A full-stack retail analytics project combining a deep-dive Jupyter EDA notebook with a multi-page React dashboard. Built on the Global Superstore dataset, the project surfaces business KPIs, profitability drivers, customer segments, geographic performance, and sales forecasts — from raw data all the way to an interactive web interface.

## Project Overview

This project answers five core business questions from retail transaction data:

- Which customers and segments contribute the most value?
- Which products, categories, and regions drive profit or loss?
- How does discounting affect profitability?
- Which shipping patterns and delays matter operationally?
- What future sales trend can be expected from historical data?

The workflow is: **raw CSV → data cleaning notebook → EDA notebook → export CSVs → React dashboard**.

## Dataset

**Source:** Global Superstore — a synthetic retail dataset commonly used for business analytics practice.

| Field | Description |
|---|---|
| Order_ID / Order_Date | Transaction identifiers and timing |
| Customer_ID / Segment | Customer key and market segment (Consumer, Corporate, Home Office) |
| Region / Country / State / City | Geographic hierarchy |
| Category / Sub-Category | Product classification (Furniture, Office Supplies, Technology) |
| Product_Name | Individual product |
| Sales / Quantity / Discount | Revenue drivers |
| Profit | Net margin after discount and cost |
| Ship_Mode / Ship_Date | Fulfilment method and lag |
| Market | Global market region (US, EU, APAC, LATAM, Africa, EMEA, Canada) |

The raw file (`Global_Superstore.csv`) requires cleaning before EDA. Run `notebooks/data_cleaning.ipynb` first to produce `data/cleaned_superstore.csv`.

## EDA Notebook

`notebooks/EDA.ipynb` — 104 cells across 15 analysis sections.

| Section | Focus |
|---|---|
| 1. Feature Validation | Schema check, type coercion, missing/duplicate audit |
| 2. Core Business KPIs | Total sales, profit, orders, margin, AOV |
| 3. Overall Distributions | Sales range, profit/loss split, order quantities |
| 4. Time-Based Analysis | Monthly trends, YoY growth, weekday patterns, seasonality |
| 5. Category & Segment Analysis | Revenue and margin by category, sub-category, and segment |
| 6. Geography Analysis | Region, country, state, city performance; loss concentration |
| 7. Shipping Analysis | Ship mode mix, delivery lag, mode profitability |
| 8. Discount & Profit Relationship | Discount bands vs margin; elasticity analysis |
| 9. Correlation Analysis | Feature-level correlation heatmap |
| 10. Outlier Analysis | High-value and anomalous transactions |
| 11. Customer & Product Analysis | RFM segmentation, top/bottom customers, product leakage |
| 12. Advanced Analytics | Forecasting, statistical tests, confidence bands |
| 13. Insight Tables | Structured exports for dashboard reuse |
| 14. Strategic Recommendations | Prioritised business actions |
| 15. Advanced Business Diagnostics | Root-cause tables, driver scorecards |

**Key findings:**
- Champions and Loyal Customers are the highest-value RFM segments.
- Discounting is the primary margin pressure lever — high discount bands are consistently loss-making.
- A small set of sub-categories (Tables, Bookcases) concentrates disproportionate losses.
- Geographic loss clusters are identifiable at state and city level.
- Time-series forecasting adds planning value for inventory and campaign timing.

## Dashboard (Web App)

An 8-page analytics dashboard built in React 19 + TypeScript, served by Vite.

| Route | Page | Description |
|---|---|---|
| `/` | Executive Dashboard | KPI cards, trend charts, top-level summaries |
| `/sales` | Sales Performance | Revenue trends, segment breakdowns, growth rates |
| `/profitability` | Profitability | Margin analysis, discount impact, profit waterfall |
| `/customers` | Customers | RFM segments, customer lifetime value, churn signals |
| `/products` | Products | Category mix, loss-making products, search by product |
| `/geography` | Geography | Regional performance, geographic drill-down, map view |
| `/reports` | Reports | Statistical validation outputs, forecast summaries |
| `/settings` | Settings | Data source info, dataset explorer |

The sidebar and header are persistent across all pages via `DashboardShell.tsx`. A command palette (`Cmd/Ctrl + K`) provides keyboard-driven navigation.

## Getting Started

### Python / Notebook Setup

Requires Python 3.11+.

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run the cleaning notebook first
jupyter notebook notebooks/data_cleaning.ipynb
# Execute all cells — produces data/cleaned_superstore.csv

# 3. Run the EDA notebook
jupyter notebook notebooks/EDA.ipynb
# Execute all cells — produces all files in exports/ and data/*.json
```

> The EDA notebook reads from `data/cleaned_superstore.csv`.
> Do not skip step 2 — the EDA will fail without the cleaned file.

### Web App Setup

Requires Node.js 18+.

```bash
# 1. Install dependencies
npm install

# 2. Start the development server
npm run dev
# App available at http://localhost:5173

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

> The web app reads data from `exports/` and `data/` at runtime.
> Run the notebooks first to ensure all CSV and JSON files are present.

```

  reads:   data/Global_Superstore.csv
  writes:  data/cleaned_superstore.csv

notebooks/EDA.ipynb
  reads:   data/cleaned_superstore.csv
  writes:  exports/*.csv (37 files)
           data/customer_search_database.json
           data/geo_search_database.json

React Dashboard
  reads:   exports/*.csv  (subset — 10 files currently wired)
           data/*.json    (all 3 search databases)
           data/cleaned_superstore.csv  (Settings page)
```
